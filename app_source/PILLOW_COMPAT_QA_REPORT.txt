OmN-e Footage Lab v0.3.1 — PILLOW COMPATIBILITY HOTFIX QA
============================================================

Issue reproduced from field report
----------------------------------
An older Linux Pillow installation can raise:
  AttributeError: module 'PIL.Image' has no attribute 'Resampling'

Cause
-----
Image.Resampling was introduced by Pillow 9.1.0. The v0.3.0 preview scaler
referenced Image.Resampling.BILINEAR directly, so a machine with an older
distro Pillow package could crash while resizing the preview.

Fix
---
- Modern Pillow: uses Image.Resampling.BILINEAR.
- Older Pillow: feature-detects the missing enum and uses the equivalent
  Image.BILINEAR constant only on that old installation.
- Preview fitting now uses Image.thumbnail() on a copy of the frame, avoiding
  a dependency on newer ImageOps.contain behaviour while preserving aspect.
- Native Windows/macOS builds pin Pillow >=11,<13 under Python 3.13.
- Diagnostics now report the Pillow version and selected resampling API.
