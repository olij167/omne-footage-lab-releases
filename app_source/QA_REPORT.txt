Hardware posture
----------------
The current pipeline is CPU-first. Integrated graphics are sufficient for the UI.
Lossless stream-copy is lightweight; H.264 filters and especially minterpolate are
CPU-heavy and may run slower than real time on old/low-power processors.

Not claimed in this environment
-------------------------------
- Real Windows executable execution.
- Real macOS package execution.
- Code-signing / Apple notarization.
- Live GitHub Actions native build for v0.3.2.
- Live Cloudflare publication of v0.3.2.

Those gates should occur before publishing a cross-platform v0.3.2 manifest.
